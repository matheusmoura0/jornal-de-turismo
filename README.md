# Jornal de Turismo

Site editorial estático para `jornaldeturismo.tur.br`, com foco em viagens, hospitalidade e aviação e preparado para receber matérias do Correio Content Hub.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Branch de produção: `main`

O site começa em modo estático para preservar a edição visual. Depois do cadastro no Hub, altere `hubEnabled` para `true` em `public/config.js` para preencher “Últimas do Turismo” automaticamente.
